# 🤝 Guía de Contribución — AgroDron v2.2 "Flora+"

¡Gracias por tu interés en contribuir a **AgroDron v2.2 "Flora+"**! Apreciamos el apoyo de la comunidad para mejorar nuestros algoritmos de visión artificial y diagnóstico agrícola.

---

## 🚀 ¿Cómo puedes contribuir?

Puedes colaborar con el proyecto en las siguientes áreas:

1. **Mejorar los modelos de visión:** Optimización de algoritmos de segmentación HSV o integración de modelos en OpenCV para detección de flora.
2. **Ampliar el catálogo taxonómico:** Agregar nuevos marcadores visuales y diagnósticos fitosanitarios de malezas o enfermedades agrícolas.
3. **Reportar errores (Bugs):** Abrir un *Issue* describiendo cualquier problema o fallo en el código.
4. **Mejorar la documentación:** Corregir errores tipográficos o ampliar la guía de instalación y uso.

---

## 🛠️ Flujo de Trabajo para Pull Requests

Para enviar cambios al repositorio, sigue este procedimiento:

1. Haz un **Fork** de este repositorio a tu cuenta personal.
2. Crea una rama (*branch*) descriptiva para tu cambio:
   ```bash
   git checkout -b feature/nueva-especie-maleza
3. Realiza tus cambios y asegúrate de mantener el estilo de código limpio en Python (PEP 8).
4. Guarda (commit) tus cambios con un mensaje claro: git commit -m "feat: añade detección de amaranto en el clasificador"
5.git push origin feature/nueva-especie-maleza
6. Abre un Pull Request (PR) hacia la rama main de este repositorio describiendo tus aportes
   Código de Conducta
Por favor mantén un ambiente de respeto, inclusión y colaboración en todas las discusiones, Issues y Pull Requests
